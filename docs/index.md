# Início

Disciplina de **Compiladores 1**, a Equipe 13 propõe o desenvolvimento de um
**interpretador para um subconjunto da linguagem C, implementado em Python**.

O projeto está organizado nas etapas clássicas de um interpretador/compilador:

- [Analisador Léxico](analisador-lexico.md)
- [Analisador Sintático](analisador-sintatico.md)
- [Analisador Semântico](analisador-semantico.md)

O [código-fonte](src.md) e os [testes](testes.md) do projeto também estão documentados aqui.

## Tecnologias

- **Linguagem:** Python
- **Documentação:** MkDocs + Material for MkDocs
- **Publicação:** GitHub Pages (deploy automático via GitHub Actions)
