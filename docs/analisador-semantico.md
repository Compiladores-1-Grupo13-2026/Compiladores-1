# Analisador Semântico

Responsável por validar o significado do programa a partir da árvore sintática
(AST), verificando regras como tipagem, escopo de variáveis e declarações
antes da interpretação.

O código correspondente a esta etapa está na pasta [`analisador_semantico/`](https://github.com/Compiladores-1-Grupo13-2026/Compiladores-1/tree/main/analisador_semantico).
