# Analisador Sintático

Responsável por verificar se a sequência de tokens gerada pelo
[analisador léxico](analisador-lexico.md) segue a gramática da linguagem,
construindo uma árvore sintática (AST) para as próximas etapas.

O código correspondente a esta etapa está na pasta [`analisador_sintatico/`](https://github.com/Compiladores-1-Grupo13-2026/Compiladores-1/tree/main/analisador_sintatico).
